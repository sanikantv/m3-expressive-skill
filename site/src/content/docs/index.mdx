## Why agents get M3 Expressive wrong

Material 3 Expressive in Compose spans many material3 versions. API names changed between 1.5.0
alphas, most of Expressive was `internal` in 1.4.0, and almost all of it became stable in the 1.5.0
betas. An agent working from memory mixes these versions up. This skill gives it the facts for
the version you actually use.

## Make one screen expressive, not every pixel

Google's research behind M3 Expressive found that people spotted key UI elements up to four
times faster on expressive screens. So the skill treats expressive design as a way to guide
attention, not as decoration. Pick the one primary action, give it a contrasting shape and the
strongest color, and save the big moments for one or two places in the product.
[Read the design rules](/reference/expressive-design/).

## Springs, not durations

`MotionScheme.expressive()` replaces fixed durations with springs. Spatial springs (size, position,
corners) may overshoot. Effects springs (color, alpha) never do. Press play to compare them; the
damping and stiffness values come straight from the material3 tokens.
