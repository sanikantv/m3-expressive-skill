## Does it work with stable material3 1.4.0?

Partly. In 1.4.0 only `ShortNavigationBar` and `WideNavigationRail` are public. The theme, motion
scheme, emphasized type and new shapes are `internal`, and button groups, the FAB menu and floating
toolbars don't exist yet. The skill tells your agent this and asks before bumping the version.
[API status by version →](/reference/api-status/)

## Which APIs still need an opt-in?

In 1.5.0-beta02, `@OptIn(ExperimentalMaterial3ExpressiveApi::class)` is needed only for these:

- `LoadingIndicator`, `ContainedLoadingIndicator`, `LoadingIndicatorDefaults`
- `MaterialShapes` with `toShape()` / `toPath()`
- one checkable `DropdownMenuItem` overload
- the pull-to-refresh loading indicator
- one `Slider` thumb overload

[The full list →](/reference/api-status/#still-opt-in-in-150-beta02)

## Which agents does it support?

Claude Code (as a plugin), and Codex, Cursor, Copilot and other `SKILL.md` readers through the
skills CLI. [Install →](/getting-started/)

## Does it cover Compose Multiplatform?

Not yet. The code targets `androidx.compose.material3` on Android.

## Does it help with Android Views?

No. MDC-Android is in maintenance mode and Material Android is Compose-first. The skill covers
Compose only.

## Is it free for commercial apps?

Yes, MIT. Material Design is a Google trademark; this project is not affiliated with Google.

## How do I know the code is right?

Every Kotlin block is compiled in CI against material3 1.5.0-beta02. [How the checks work →](/changelog/)
