The skill is a folder with a `SKILL.md` and seven reference files. Your agent reads the short
`SKILL.md` on every Compose UI task, and opens a reference file only when it needs it.

## 1. Install it

<Install />

Check that it loaded. In Claude Code, `/m3-expressive-compose` should appear when you type `/m3`.

## 2. Point your project at material3 1.5.0

Expressive needs material3 **1.5.0**. In 1.4.0 most of it is `internal`. The skill checks your
version first and tells you if it is too old, but you can set it up now:

```toml
# gradle/libs.versions.toml
[versions]
material3 = "1.5.0-beta02"

[libraries]
androidx-compose-material3 = { group = "androidx.compose.material3", name = "material3", version.ref = "material3" }
```

A Compose BOM won't move material3 to a beta, so pin it explicitly as above.

## 4. Ask for something

```text
Build a settings screen with segmented list items, a large flexible top app bar,
and a floating toolbar with a FAB.
```

```text
/m3-expressive-compose review app/src/main/java/com/example/HomeScreen.kt
```

What you should see the agent do:

- Read `material3` from your version catalog before writing code.
- Use `SegmentedListItem` with `ListItemDefaults.segmentedShapes(index, count)`, not cards of
  `ListItem`s.
- Add `@OptIn(ExperimentalMaterial3ExpressiveApi::class)` only where it uses `LoadingIndicator`
  or `MaterialShapes`.
- Animate with `MaterialTheme.motionScheme` springs, not `tween(300)`.
