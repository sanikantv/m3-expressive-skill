**Short answer:** set `material3` to **1.5.0-beta02**, wrap your app in `MaterialExpressiveTheme`,
and use the Expressive components (`ButtonGroup`, `FloatingActionButtonMenu`,
`HorizontalFloatingToolbar` …). In beta02 almost none of them need an opt-in.

## Why it isn't just "update Compose"

M3 Expressive shipped in Compose as part of material3 **1.5.0**. In the stable 1.4.0, the
Expressive theme, motion scheme and emphasized type exist but are `internal`, and most new
components aren't there. A Compose BOM won't move material3 to a beta, so you need to pin it.

## 1. Pin the version

```toml
# gradle/libs.versions.toml
[versions]
material3 = "1.5.0-beta02"

[libraries]
androidx-compose-material3 = { group = "androidx.compose.material3", name = "material3", version.ref = "material3" }
```

## Common mistakes

- Adding `@OptIn(ExperimentalMaterial3ExpressiveApi::class)` everywhere. In beta02 only `LoadingIndicator`, `MaterialShapes` and a few helpers need it. [Full list](/reference/api-status/).
- Keeping `tween()` animations in custom UI. Use [MotionScheme springs](/guides/spring-animations-motionscheme/).
- Using a deprecated API like `ListItem(headlineContent = …)`. [What changed](/guides/material3-1-5-0-migration/).
