In 1.5.0-beta02 the old `SearchBar(query, onQueryChange, onSearch, active, onActiveChange, …)`
and `DockedSearchBar` are deprecated. The new `SearchBar(state, inputField)` is stable. It holds
text in a `TextFieldState`, and you show results in a separate expanded composable.

<Snippet region="search-bar" />

For a search field inside a top app bar, use `AppBarWithSearch` (renamed from `TopSearchBar`,
still `@ExperimentalMaterial3Api`).

Related: [API status: deprecations](/reference/api-status/) · [flexible top app bar](/components/flexible-top-app-bar/)
