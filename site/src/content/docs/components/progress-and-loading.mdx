| Wait | Use |
|---|---|
| Known progress, visible for a while (download, upload) | `LinearWavyProgressIndicator(progress = { … })` |
| Unknown, short (loading a screen or list) | `LoadingIndicator()`, opt-in |
| Over content or in pull-to-refresh | `ContainedLoadingIndicator()`, opt-in |
| Dense or utilitarian UI | Flat `LinearProgressIndicator` / `CircularProgressIndicator` |

The wavy indicators are stable in 1.5.0-beta02:

The demo above uses the real `IndeterminateIndicatorPolygons` sequence (SoftBurst, Cookie9Sided,
Pentagon, Pill, Sunny, Cookie4Sided, Oval) and `Morph` output from `androidx.graphics.shapes`.

In Google's examples the wave flattens into a straight bar when the work finishes. The track keeps
a gap and a stop dot at the end.
