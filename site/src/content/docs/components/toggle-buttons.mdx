`ToggleButton`, `FilledTonalToggleButton`, `ElevatedToggleButton` and `OutlinedToggleButton`
(new in 1.5.0, stable in beta02) hold an on/off state. When checked they change **color and
shape**: round when off, squarer when on.

<Snippet region="toggle-button" />

## When to use

- A state that sticks: follow, favorite, bold, mute.
- Use a [connected button group](/components/button-groups/) to choose one option from several.
- Use a `Switch` for a setting that takes effect immediately in a list.

## Accessibility

`ToggleButton` already reports its checked state. Make the label say what it does ("Follow" /
"Following"), not "On" / "Off".
