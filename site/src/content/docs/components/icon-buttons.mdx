`IconButton`, `FilledIconButton`, `FilledTonalIconButton` and `OutlinedIconButton` take
`shapes = IconButtonDefaults.shapes()` for the press morph, and size with
`IconButtonDefaults.extraSmallContainerSize()` through `extraLargeContainerSize()`.

<Snippet region="icon-button-shapes" />

For toggles (`IconToggleButton` and its variants) use `IconButtonDefaults.toggleableShapes()`.
Selection then changes shape as well as color.

## Accessibility

Always set `contentDescription`. Add a tooltip when the icon's meaning isn't obvious. Keep the
touch target at 48dp or more, even when the visible container is smaller.
